# 👑 Empire Conquest - فتح امپراطوری

## 🎮 بازی استراتژی نبردی جذاب برای اندروید

**Empire Conquest** یک بازی استراتژی پویا است که در آن شما باید:
- 🏰 امپراطوری خود را ساخت و تقویت کنید
- ⚔️ با دشمنان و بازیکنان دیگر جنگ کنید
- 💰 منابع مختلف جمع‌آوری و مدیریت کنید
- 👑 برای بالاترین رتبه رقابت کنید
- 🎖️ مدال‌های پیروزی کسب کنید

## ✨ ویژگی‌های اصلی

✅ **سیستم ساخت و ارتقا** - قلعه‌ها و ساختمان‌های متنوع  
✅ **نبرد هوشمند** - هوش مصنوعی چالش‌برانگیز  
✅ **مدیریت منابع** - چهار نوع منبع اصلی  
✅ **سیستم تجربه** - سطح‌بندی و ارتقای شخصیت  
✅ **رتبه‌بندی جهانی** - رقابت با سایرین  
✅ **گرافیک جذاب** - رنگارنگ و انیمیشن‌ها  
✅ **طراحی سهل** - برای تمام سطوح بازیکنان  

## 🛠️ سیستم‌های بازی

### 🏗️ ساختمان‌ها (7 نوع)
- **قلعه اصلی** - مرکز امپراطوری
- **آرزنال** - تربیت سربازان
- **مزرعه** - تولید غذا
- **معدن** - استخراج سنگ
- **برج دفاعی** - دفاع امپراطوری
- **دیوار** - محافظت ایستاده
- **انبار** - ذخیره منابع

### ⚔️ واحدهای نظامی (5 نوع)
- **سرباز** - واحد پایه
- **تیرانداز** - حمله از راه دور
- **شوالیه** - دفاع قوی
- **جادوگر** - حمله قوی
- **سوارکار** - سرعت بالا

### 💰 منابع
- **طلا** - منبع اصلی
- **سنگ** - ساخت دفاعات
- **چوب** - ساخت عمومی
- **غذا** - تغذیه سربازان

## 🎮 نحوه بازی

1. **شروع بازی** - امپراطوری کوچک و منابع اولیه
2. **ساختمان سازی** - بسازید و ارتقا دهید
3. **جمع‌آوری منابع** - منابع را جمع کنید
4. **تربیت سربازان** - ارتش خود را تقویت کنید
5. **جنگ** - دشمنان را شکست دهید
6. **Leveling Up** - سطح خود را بالا ببرید
7. **برتری** - در رتبه‌بندی جهانی صعود کنید

## 📱 مشخصات فنی

- **Engine:** Unity 2022+
- **Language:** C#
- **Platform:** Android 6.0+
- **Graphics:** 2D
- **Size:** ~ 100MB (تقریبی)

## 🚀 نصب و اجرا

### نیازمندی‌ها
- Unity 2022.3 یا بالاتر
- Android SDK
- حداقل 2GB RAM

### مراحل نصب

```bash
# Clone کردن
git clone https://github.com/Radinkaboodi/empire-conquest.git
cd empire-conquest

# باز کردن در Unity
# File → Open Project → انتخاب این فولدر

# Build برای Android
# File → Build Settings → Android → Build and Run
```
